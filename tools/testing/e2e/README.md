# End-to-end experience tests

真实启动 Debug 版 Pastable，用 macOS Accessibility API 驱动界面，并用一个临时
文档夹具验证「呼出 → 搜索/筛选 → 选择 → 回贴」的完整体验。

## 运行

```bash
./tools/testing/e2e/run.sh
```

需要：

- 已登录的图形会话（有 WindowServer）
- Xcode 16+
- 终端 / 运行器具备「辅助功能」与「屏幕录制」权限
- 不会碰用户的真实数据：使用独立 bundle id `com.qzh.Pastable.e2e`、临时
  SwiftData 目录、临时偏好域，并在结束时恢复系统剪贴板

## 覆盖

- 空状态与面板几何：全屏宽、贴物理底边、层级高于 Dock、五个分类、搜索框
- 种子历史渲染：文本/代码/链接/图片/多文件/富文本、相对时间与大小
- 分类筛选：文本、代码、链接、媒体
- 真实键盘搜索：输入、命中、无结果空态、清空
- 键盘：`Cmd+1` 快贴、方向键选择 + `Enter`、`Cmd+Delete` 删除
- 鼠标：点击卡片复制、图片复制、多文件复制、去格式复制
- 状态栏：开合面板、Escape 关闭、外点关闭、更多菜单、从菜单进设置、退出
- 真实回贴：把内容自动 `Cmd+V` 到文档夹具
- 设置：四个标签页、容量与 iCloud 文案、开关持久化、清空历史的确认与取消
- 本地化与主题：英文标签、明暗主题亮度对比
- 持久化：重启后历史仍在、删除不复活、种子不重复
- 性能计时：启动到面板、搜索、筛选、复制的响应时间

## 产物

`build/test-reports/e2e-<timestamp>/`：

- `report.json`：每条检查的状态、耗时、失败详情
- `01-empty-dark.png` … `08-collection-light.png`：关键状态截图
- `app-*.log`：每个实例的标准输出/错误

## 已知问题策略

与需求/文档不一致、但确认是产品行为的问题记为 `KNOWN ISSUE`，不计入
非预期失败（退出码仍为 0），并在报告末尾单独列出。真正的测试驱动故障记为
`FAIL`，退出码为 1。

**当前已知问题：0。**

2026-10-31 修复并转为普通断言的回归项：

1. **面板打开后键入被吞**：面板不再抢焦点，全局键盘 tap 只截获导航键；
   搜索框首击延迟聚焦，blur 时归还文档焦点。
2. **多文件卡片标题漂移**：卡片优先使用初始化时按复制顺序持久化的标题。

这两项一旦回退，端到端测试会直接失败。

## 限制

- 没有触发全局快捷键 `Cmd+Shift+V`：本机同时运行着已安装的 Pastable，同一
  快捷键会争抢注册；面板开关使用状态栏点击（与真实点击同一条路径）。
- 全局键盘导航需要「输入监控」权限；缺失时 tap 不会安装，鼠标与文档键入不受影响。
- 搜索输入使用真实键码，并按中文输入法行为发送空格提交；不做 IME 候选评测。
- StoreKit 评分弹窗、CloudKit 网络同步、Accessibility 权限被拒绝的分支不在
  此套件内（逻辑层单测已覆盖决策与降级）。
