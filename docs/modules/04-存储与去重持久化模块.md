# 04 存储与去重持久化模块

## 模块定位

基于 SwiftData 管理历史记录落盘、去重更新、过期清理和存储体积读取，是数据一致性核心模块。

## 涉及文件

- `Pastable/Persistence/Storage.swift`

## 核心能力

### 1) SwiftData 容器初始化

- 单例 `Storage.shared`。
- 数据库路径：`Application Support/Pastable/Storage.sqlite`。
- `DEBUG + enable-testing` 参数下切换为内存数据库，方便测试。

### 2) 存储体积展示

- `size` 读取数据库文件字节数并格式化。
- 可用于设置页或诊断信息展示。

### 3) 历史清理

- `cleanup(retentionDuration:)`：
  - `duration <= 0` 直接跳过（无限保留）。
  - 按 `firstCopiedAt < cutoffDate` 查询并删除。
  - 删除后统一 `context.save()`。

### 4) 新增或更新（去重）

`addOrUpdate(_:)` 核心行为：

1. 确保新项 `contentHash` 已生成。
2. 优先按 hash 反查历史记录（按时间倒序）。
3. 若没命中，补算最近 200 条未带 hash 的旧数据并回填。
4. 使用 `supersedes` 判断“内容覆盖关系”。
5. 命中重复：
   - 更新时间戳（置顶）
   - `numberOfCopies + 1`
   - 更新来源应用
6. 未命中：插入新记录。
7. 保存上下文。

## 对外接口

- `cleanup(retentionDuration:)`
- `addOrUpdate(_:)`
- `container` / `context` / `size`

## 与其他模块的协作

- 被 `AppDelegate` 在启动时触发清理。
- 被 `Clipboard` 在采集后调用写入。
- 被 `PastableApp` 注入 `modelContainer` 到 UI。
- 被 `ContentView`/设置页通过 `@Query` 直接读取。

## 设计特点

- 双层去重：
  - 采集层（`Clipboard`）短窗 fingerprint 去抖。
  - 存储层（`Storage`）hash + 内容覆盖校验去重。
- 兼容历史数据迁移：回填缺失 `contentHash`，减少重复插入。

## 已知约束

- `historySize`（历史条数上限）目前仅有设置项，尚未在存储层执行硬裁剪。
- 清理只基于时间，不按类型或条数做组合策略。
- 异常处理当前以 `print` 为主，尚未接入统一日志系统。
