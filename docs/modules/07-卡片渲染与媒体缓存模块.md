# 07 卡片渲染与媒体缓存模块

## 模块定位

负责剪贴板历史卡片的视觉渲染、媒体资源加载（缩略图/图标）、富文本背景提取与缓存加速，是主界面的性能关键模块。

## 涉及文件

- `Pastable/UI/Components/CardCell.swift`
- `Pastable/Core/ImageCache.swift`
- `Pastable/Extensions/NSImage+Extensions.swift`
- `Pastable/Extensions/NSAttributedString+Extensions.swift`

## 核心能力

### 1) 多类型卡片渲染

`CardCell` 根据 `HistoryItem` 内容分支渲染：

- 直接图片：显示原图预览。
- 文件：
  - 图片文件：缩略图。
  - 非图片文件：文件图标。
- 文本/代码/链接：文本预览。
- 十六进制颜色文本：整块颜色预览。

页脚统一展示：相对时间、字符数、类型标签。

### 2) 异步资源加载

`task(id: persistentModelID)` 中并行执行：

- 图片文件缩略图加载。
- 来源应用图标加载。
- 非图片文件图标加载。
- RTF 文本解析与背景色提取。

全部采用“后台加载 -> 主线程回填 -> ID 校验防串位”模式。

### 3) 缓存策略（`ImageCache`）

- `appIconCache`：按 bundle id 缓存应用图标。
- `fileIconCache`：按文件路径缓存文件图标。
- `thumbnailCache`：按 URL 缓存缩略图。
- 三类缓存 `countLimit = 200`，降低滚动中的重复 I/O 与解码开销。

### 4) 自适应主题色生成

- `NSImage.averageColor()` 对图标像素采样并聚类。
- 使用面积 + 饱和度评分选主色，避免灰色背景色主导。
- 对过亮颜色做柔和压缩，适配深色界面可读性。
- 计算结果写入 `item.cachedAdaptiveHexColor`，后续直接复用。

### 5) 富文本优化

- 从 RTF 数据重建 `AttributedString`，用于更接近原样显示。
- 提取首字符背景色（或缓存值）作为卡片内容背景。
- 若成功解析背景色且未缓存，则写入 `cachedRTFBackgroundHexColor`。

## 性能与正确性设计

- 通过 `item.persistentModelID` 验证异步回写目标，避免 cell 复用造成错配。
- 对高成本状态（缩略图、图标、RTF 转换）关闭隐式动画，减少闪烁。
- 数据层提前缓存 `previewableText/title`，降低 UI 每帧解析负担。

## 对外接口（渲染层）

- `CardCell(item:isSelected:onCopy:)`
- `ImageCache.appIcon/fileIcon/thumbnail`
- `NSImage.averageColor()`
- `NSAttributedString.effectiveBackgroundColor`

## 已知约束

- 缓存仅内存级，应用重启后失效。
- 缩略图加载依赖文件可访问性，受沙盒/路径权限影响。
- `isSelected` 当前在视觉上未做明显区分（保留参数但未形成独立样式分支）。
