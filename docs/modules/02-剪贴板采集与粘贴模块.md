# 02 剪贴板采集与粘贴模块

## 模块定位

负责系统剪贴板轮询、内容快照采集、重复内容去抖、写回剪贴板以及模拟粘贴动作，是业务数据入口与输出执行层。

## 涉及文件

- `Pastable/Core/Clipboard.swift`
- `Pastable/Extensions/NSPasteboard+Types.swift`

## 核心能力

### 1) 剪贴板变化监听

- 使用 `Timer` 每 1 秒轮询 `NSPasteboard.general.changeCount`。
- 仅在 `changeCount` 变化时进入采集流程。
- 对快速连续写入采用 150ms 合并（`DispatchWorkItem`），减少同一次复制被多次记录。

### 2) 支持与忽略的数据类型

- 支持类型：`fileURL/html/png/rtf/string/tiff`。
- 忽略类型：`AutoGenerated/Concealed/Transient/fromPastable`。
- 目的：
  - 过滤系统/应用内部过渡类型。
  - 通过 `fromPastable` 防止“应用自己写回 -> 被再次采集”的回环。

### 3) 快照构建与标准化

- 对每个 `pasteboardItem`，遍历受支持类型并抓取原始 `Data`。
- 生成 `HistoryItemContent(type, value)` 列表。
- 构造 `HistoryItem(contents:)`，并记录来源应用 bundle id。

### 4) 采集端快速去重

- 为每次快照计算 `fingerprint`（优先 text -> files -> image -> rtf -> html -> raw）。
- 若与上次 fingerprint 相同且间隔 < 1 秒，直接跳过。
- 此层用于抑制“同内容短时间重复触发”；长期去重由存储层负责。

### 5) 入库触发与 UI 通知

- 在主线程调用 `Storage.shared.addOrUpdate(historyItem)`。
- 写入后置 `AppState.shared.shouldScrollToTop = true`，提示列表滚到最前。

### 6) 剪贴板回写与粘贴执行

- `copy(_ item)`：将历史内容逐 type 回写到系统剪贴板，并写入 `fromPastable` 标记。
- `paste()`：使用 `CGEvent` 模拟 `Cmd + V`（固定虚拟键码 `kVK_ANSI_V = 9`）。
- `paste(_ item)`：先 copy，延迟 100ms 后触发 paste。
- 可选音效：读取 `playSounds`，播放系统 `Tink`，失败回退 `beep`。

## 关键流程（采集）

1. 轮询发现 `changeCount` 变化。
2. 延迟 150ms 合并更新。
3. 跳过忽略类型。
4. 读取支持类型并构建 `HistoryItem`。
5. fingerprint 短窗口去重。
6. 写入存储并通知 UI 滚动。

## 关键流程（粘贴）

1. UI 触发粘贴目标项。
2. `copy(item)` 回写完整 pasteboard 数据。
3. 关闭面板（由 UI 编排）。
4. `paste()` 发送 `Cmd + V` 事件。

## 配置项

- `playSounds`（`UserDefaults`）：是否播放粘贴提示音。
- 内部 `enabledTypes` 目前硬编码，尚未接入设置页（代码中已有 TODO）。

## 依赖关系

- 上游：`AppDelegate` 调用 `start()`。
- 下游：`HistoryItem`、`Storage`、`AppState`。
- 系统：`NSPasteboard`、`CGEvent`、`NSWorkspace`。

## 已知约束

- 监听采用轮询而非系统推送，理论上存在秒级检测粒度。
- 只处理 `supportedTypes` 集合内内容，其他格式会被忽略。
- `pasteAutomatically/removeFormatting` 设置项目前未接入执行链路。
