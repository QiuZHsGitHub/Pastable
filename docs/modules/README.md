## 代码层模块关系

1. `PastableApp` 启动后将控制权交给 `AppDelegate`。
2. `AppDelegate` 启动 `Clipboard` 监听并创建 `FloatingPanel` + `ContentView`。
3. `Clipboard` 采集到快照后创建 `HistoryItem` 并交给 `Storage` 去重入库。
4. `ContentView` 通过 `@Query` 读取数据并同步到 `AppState`。
5. `AppState` 统一执行搜索与分类筛选，输出 `displayItems`。
6. UI 组件渲染 `displayItems`，用户点击后通过 `Clipboard` 完成复制与粘贴。
7. 设置页通过 `@AppStorage` 写入偏好，核心模块按 key 读取行为配置。

## 2026-10 更新

> 本目录最初按早期实现编写，部分描述（如 1 秒轮询、设置项未接入、`firstCopiedAt` 排序）已经过时。当前实现请以源码和根目录 README 为准，主要变化：
>
> - 采集间隔改为 0.3 秒并接入 `.common` run loop；保存类型、自动粘贴、去除格式等设置已全部接入执行链路。
> - 去重以 `contentHash` 为准，能合并仅格式不同的内容，并会惰性清理历史重复行。
> - 历史上限/保留时间会真正执行；首次发现旧库超限时提供「清理 / 全部保留 / 稍后」选择，不会静默删除。
> - 截图等 TIFF 数据在后台转 PNG；多文件回写改为每个文件一个 pasteboard item。
> - 搜索覆盖完整内容、多关键词与排序；新增自动聚焦、`←/→` 选择、`Enter` 粘贴、`Cmd/Fn + 1…9` 快贴、空状态与辅助功能权限提示。
