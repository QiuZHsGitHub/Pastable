# 01 应用入口与生命周期模块

## 模块定位

负责应用启动流程、托盘入口、面板窗口生命周期、全局快捷键注册与开关控制，是整套系统的运行编排层。

## 涉及文件

- `Pastable/PastableApp.swift`
- `Pastable/Core/AppDelegate.swift`
- `Pastable/UI/FloatingPanel.swift`
- `Pastable/Extensions/KeyboardShortcuts+Extensions.swift`

## 核心能力

### 1) 应用启动与依赖装配

- 使用 `@main` 的 `PastableApp` 作为入口。
- 通过 `@NSApplicationDelegateAdaptor(AppDelegate.self)` 将生命周期托管给 `AppDelegate`。
- 在 `Settings` scene 注入 `Storage.shared.container`，确保设置页面可访问 SwiftData。

### 2) 全局快捷键与托盘入口

- 默认快捷键定义为 `Cmd + Shift + V`（`togglePanel`）。
- `AppDelegate.applicationDidFinishLaunching` 中注册 `KeyboardShortcuts.onKeyDown` 回调。
- 创建 `NSStatusItem` 状态栏图标，点击触发同一 `togglePanel` 逻辑。

### 3) 浮层窗口创建与控制

- 启动时创建 `FloatingPanel`，并设置：
  - `nonactivatingPanel + borderless + fullSizeContentView`
  - `isFloatingPanel = true`, `level = .statusBar`
  - `canJoinAllSpaces + fullScreenAuxiliary`
  - `hidesOnDeactivate = false`，失焦不隐藏
- 通过 `setContent(view:)` 挂载 `ContentView`（注入 `modelContainer` 与 `AppState`）。
- 面板是「搁架」：显式关闭，不随焦点丢失关闭。
- `openPanel()` 行为：
  - 激活 App（保证键盘事件）
  - 重新定位到底部
  - 打开面板并重置搜索词
- `closePanel()` 统一关闭并回写 `AppState.shared.isPanelVisible = false`。

### 4) 关闭策略（显式关闭）

- 不再监听 `resignKey()` / `NSApplication.didResignActiveNotification` 自动关闭：
  切换窗口、Cmd+Tab、切换 Space / 进入全屏都会短暂失焦，旧逻辑会让面板「闪一下就没」。
- 关闭时机只有：
  - `Esc`
  - 再次按全局快捷键 / 点击状态栏图标
  - 点击面板外任意位置（其他 App 窗口、菜单栏、Dock、桌面都算）
  - 完成一次粘贴
- 同时注册本地与全局鼠标监控捕获点击位置（`handleOutsideClick(at:)`）。点击在
  面板自身窗口、状态栏图标、设置窗口、面板弹出的菜单/popover 上时不算「面板外」；
  `NSApp.windows` 只检查 `isOnActiveSpace` 的窗口，另外用 WindowServer 列表
  （`isPoint(_:coveredBy:ownedBy:)`）补上 AppKit 的私有 popover/menu 窗口。
- 面板失焦后再次被点击时激活 App（`panelClickMonitor`），否则搜索框会获得光标但
  按键仍发给前台 App；点击卡片则会先关闭面板，由粘贴目标决定最终前台 App。

### 5) 跨 Space 与粘贴目标

- 监听 `NSWorkspace.activeSpaceDidChangeNotification`，切换 Space / 全屏后
  `reassertOnActiveSpace()` 把面板重新前置（不抢焦点）。
- 监听 `NSApplication.didChangeScreenParametersNotification`，显示器变化后重新贴底。
- 监听 `NSWorkspace.didActivateApplicationNotification` 记录最近的前台普通 App。
  面板保持打开期间用户可能已切换 App，粘贴时 `pasteTargetApplication()` 优先当前
  前台 App（仅接受 `.regular` 激活策略，排除控制中心 / Dock 等系统 UI），
  再回退到打开面板时记录的应用，确保 Cmd+V 落到正确的 App。

### 6) 启动期历史清理

- 启动后读取 `historyRetentionDuration`（秒）。
- 大于 0 时在后台 `Task` 调用 `Storage.cleanup` 清理过期历史，避免阻塞启动。

## 关键流程

1. 启动 App。
2. `AppDelegate` 注册自身到 `AppState`。
3. 启动剪贴板监听（`Clipboard.start`）。
4. 注册快捷键与状态栏图标行为。
5. 创建面板并装载 `ContentView`。
6. 注册外部点击监听与 Workspace 通知。
7. 执行历史清理。

## 对外接口

- `togglePanel()`：面板开关入口（快捷键/状态栏共用）。
- `openPanel()`：显示面板。
- `closePanel(restorePrevious:)`：关闭面板，可选恢复上一个前台 App。
- `pasteTargetApplication()`：解析当前应接收 Cmd+V 的 App。
- `FloatingPanel.positionAtBottom()`：面板重定位。
- `FloatingPanel.reassertOnActiveSpace()`：Space / 全屏切换后重新前置面板（不抢焦点）。

## 依赖关系

- 上游：macOS 生命周期。
- 下游：`Clipboard`、`Storage`、`AppState`、`ContentView`。
- 第三方：`KeyboardShortcuts`。

## 已知约束

- 面板定位取鼠标所在屏幕（`NSScreen.screens` + `NSEvent.mouseLocation`），而不是
  `NSScreen.main`；多显示器下贴鼠标所在屏幕的物理底边。
- 面板保持打开但切到其他 App 后，键盘事件属于前台 App；点击面板会重新激活
  Pastable，点击卡片则直接粘贴到当前前台 App（`activationPolicy == .regular`）。
- 点击面板外会立即关闭面板，同时该点击照常交给目标窗口；`Cmd+Tab` / 切 Space
  这类没有点击的焦点变化则不会关闭面板。
- Dock 图标策略固定为 `.accessory`（应用以菜单栏形态运行）。
