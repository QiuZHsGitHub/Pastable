# 08 设置中心与偏好项模块

## 模块定位

提供用户可见配置入口，统一管理行为偏好、存储策略、快捷键与关于信息。

## 涉及文件

- `Pastable/UI/Settings/SettingsView.swift`
- `Pastable/UI/Settings/GeneralSettingsView.swift`
- `Pastable/UI/Settings/StorageSettingsView.swift`
- `Pastable/UI/Settings/ShortcutsSettingsView.swift`
- `Pastable/UI/Settings/AboutSettingsView.swift`

## 页面结构

`SettingsView` 使用 `TabView` 提供 4 个页签：

1. General
2. Storage
3. Shortcuts
4. About

窗口层面通过 `WindowAccessor` 设置 `window.level = .modalPanel` 并居中显示。

## 各子模块功能

### 1) GeneralSettingsView

配置项（`@AppStorage`）：

- `launchAtLogin`
- `pasteAutomatically`
- `removeFormatting`
- `playSounds`
- `searchMode`（`exact/fuzzy`）

当前已接入行为：

- `searchMode`：影响 `AppState` 搜索策略。
- `playSounds`：影响 `Clipboard` 粘贴音效。

### 2) StorageSettingsView

配置项（`@AppStorage`）：

- `historySize`
- `saveFiles`
- `saveImages`
- `saveText`
- `historyRetentionDuration`

能力：

- 配置历史条数上限（UI 侧）
- 配置保留时长（启动清理由 `AppDelegate + Storage.cleanup` 执行）
- 一键清空历史（删除所有 `@Query items`）

### 3) ShortcutsSettingsView

- 使用 `KeyboardShortcuts.Recorder` 配置 `togglePanel` 快捷键。
- 对应 `AppDelegate` 监听回调即时生效。

### 4) AboutSettingsView

- 展示应用图标、名称、版本和描述文案。

## 与核心模块联动

- `searchMode` -> `AppState/SearchService`
- `playSounds` -> `Clipboard`
- `historyRetentionDuration` -> 启动时 `Storage.cleanup`
- 快捷键 -> `AppDelegate.togglePanel`
