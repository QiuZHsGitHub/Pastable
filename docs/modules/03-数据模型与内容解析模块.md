# 03 数据模型与内容解析模块

## 模块定位

定义历史记录核心数据结构，并提供内容解析、标题生成、类型判断（代码/链接/文件/图片/颜色）、OCR 识别与内容哈希能力。

## 涉及文件

- `Pastable/Models/HistoryItem.swift`
- `Pastable/Models/HistoryItemContent.swift`

## 数据结构

### `HistoryItemContent`

- 字段：
  - `type: String`（pasteboard type）
  - `value: Data?`（原始内容）
  - `item: HistoryItem?`（反向关联）
- 与 `HistoryItem` 为一对多关系。

### `HistoryItem`

- 元数据：
  - `application`：来源应用 bundle id
  - `firstCopiedAt/lastCopiedAt`
  - `numberOfCopies`
  - `pin`
- 展示缓存：
  - `title`
  - `cachedPreviewText`
  - `cachedAdaptiveHexColor`
  - `cachedRTFBackgroundHexColor`
- 去重辅助：
  - `contentHash`
- 关联：
  - `contents: [HistoryItemContent]`（`deleteRule: .cascade`）

## 核心能力

### 1) 初始化与预计算

- `init(contents:)` 时立即计算：
  - 预览文本 `cachedPreviewText`
  - 标题 `title`
  - 内容哈希 `contentHash`
- 目的：降低列表渲染期重复解析开销。

### 2) 内容提取与派生属性

- 文本：`text`
- 富文本：`rtfData/rtf`
- HTML：`htmlData/html`
- 图片：`imageData/image`（支持 `tiff/png/jpeg/heic`）
- 文件：`fileURLs`
- 通用剪贴板标记：`universalClipboard`

### 3) 预览文本与标题生成

- `previewableText` 优先级：文件路径 > 文本 > RTF > HTML > 标题。
- `generateTitle()`：
  - 图片：异步触发 OCR（Vision）后回填标题。
  - 文件：优先显示文件名。
  - 文本：截断至 1000 字符，并清理前后空白。

### 4) 类型识别

- `isCode`：启发式打分（字母数字占比、括号/括弧配对、关键词、注释、行尾符号等）。
- `isLink`：`NSDataDetector` 严格检测且要求匹配覆盖整串文本。
- `isImage` / `isImageFile` / `isFile`：基于内容与 `UTType` 判断。
- `hexColor`：正则匹配纯十六进制颜色值（`#RGB/#RRGGBB/#AARRGGBB`）。

### 5) OCR 文本识别

- 对图片内容创建 `VNRecognizeTextRequest`。
- 识别语言：`zh-Hans`, `en-US`。
- 将识别结果拼接后写回 `title`。

### 6) 内容比较与哈希

- `supersedes(_:)`：忽略 transient type 后，判断当前项是否覆盖目标项全部内容。
- `computeContentHash(contents:)`：
  - 优先 text
  - 其次 files
  - 再 image
  - 再 rtf/html
  - 最后 raw
- 哈希算法：SHA-256（并加入类型前缀，增强可解释性）。

## 对外接口（高频）

- `generateTitle()`
- `supersedes(_:)`
- `computeContentHash(contents:)`
- `loadThumbnail(for:maxPixelSize:)`
- 计算属性：`isCode/isLink/isImage/isFile/previewableText/...`

## 依赖关系

- 上游：`Clipboard` 负责构造实例。
- 下游：`Storage` 依赖 `contentHash` 与 `supersedes` 去重。
- UI：`CardCell` 大量消费派生属性。
- 系统框架：`Vision`, `CryptoKit`, `UniformTypeIdentifiers`。

## 已知约束

- 代码识别为启发式算法，非语法解析，存在误判可能。
- OCR 在图像项初始化后异步执行，标题更新存在短暂延迟。
- `showSpecialSymbols` 逻辑预留但未开放设置入口。
