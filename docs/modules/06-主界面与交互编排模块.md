# 06 主界面与交互编排模块

## 模块定位

承载主面板的布局与事件编排，连接“用户动作 -> 业务执行 -> 状态更新”的交互链路。

## 涉及文件

- `Pastable/ContentView.swift`
- `Pastable/UI/Components/HeaderView.swift`
- `Pastable/UI/Components/CategoryFilter.swift`
- `Pastable/UI/Components/SearchBar.swift`
- `Pastable/UI/Components/CardList.swift`
- `Pastable/UI/Components/MoreMenuView.swift`
- `Pastable/UI/Components/VisualEffectView.swift`

## 核心能力

### 1) 主视图编排（`ContentView`）

- 上半部分：`HeaderView`（分类 + 搜索 + 更多菜单）。
- 下半部分：`CardList`（横向卡片列表）。
- 背景使用 `VisualEffectView(material: .menu)`，顶部圆角裁切。
- 生命周期：
  - `onAppear` 同步初始数据并注册键盘监听。
  - 监听 `items` 变化并调用 `appState.updateItems`。

### 2) 粘贴行为编排

`performPaste(item)` 顺序：

1. 关闭面板。
2. 更新时间（将记录置顶）。
3. 回写剪贴板内容。
4. 触发 `Cmd + V` 模拟粘贴。

### 3) 快捷键交互

- `HeaderView` 注入隐藏按钮绑定 `Cmd + Shift + F` 聚焦搜索框。
- `CardList` 注入隐藏按钮绑定 `Cmd + Delete` 删除当前悬浮项。
- `ContentView.setupKeyboardMonitor` 支持 `Fn + 1...9` 直接粘贴对应序号卡片。

### 4) 搜索与分类交互

- `CategoryFilter` 点击后切换 `selectedCategory`。
- `SearchBar`：
  - 输入搜索词。
  - 一键清空搜索词。
  - 焦点状态驱动图标/边框高亮。
  - 接收 `AppState.searchFocusRequest` 执行 focus/blur。

### 5) 更多菜单能力

`MoreMenuView` 提供：

- 清空历史（有历史时显示）
- 打开设置
- 跳转关于页
- 退出应用

支持 macOS 14+ 使用 `SettingsLink`，低版本回退手动 action。

### 6) 列表滚动与焦点协同

- 监听 `shouldScrollToTop`，新内容入库后自动滚到最前。
- 点击列表区域时发出 `blur` 请求，让搜索框失焦。

## 交互主流程

1. 用户快捷键/状态栏打开面板。
2. 输入搜索词 + 选择分类。
3. 点击卡片或按 `Fn + 数字` 触发粘贴。
4. 面板关闭，目标应用收到粘贴。

## 已知约束

- `Fn + 数字` 在不同键盘映射下可能事件行为不一致。
- 列表为横向滚动，超长文本内容依赖卡片内截断展示。
- 菜单中的“清空历史”由 UI 直接删 `@Query items`，未走统一服务层封装。
