# 09 主题国际化与基础扩展模块

## 模块定位

提供主题色体系、颜色转换、时间/文本格式化、本地化文案和 Pasteboard 类型常量，支撑上层业务模块的统一能力复用。

## 涉及文件

- `Pastable/Core/ThemeManager.swift`
- `Pastable/Extensions/Color+Extensions.swift`
- `Pastable/Extensions/Date+Extensions.swift`
- `Pastable/Extensions/String+Shortened.swift`
- `Pastable/Extensions/NSPasteboard+Types.swift`
- `Pastable/Extensions/KeyboardShortcuts+Extensions.swift`
- `Pastable/Resources/en.lproj/Localizable.strings`
- `Pastable/Resources/zh-Hans.lproj/Localizable.strings`
- `Pastable/Resources/zh-Hant.lproj/Localizable.strings`

## 核心能力

### 1) 主题系统

- `ThemePalette` 定义语义色：`text/code/link/other/all`。
- 内置色板：`deepElegant`, `vibrant`, `muted`。
- `ThemeMode` 提供模式枚举（含 `adaptive/custom`）。
- `ThemeManager` 当前固定 `currentMode = .adaptive`。

### 2) 颜色工具

- `Color(hex:)` 支持 3/6/8 位十六进制解析。
- 定义品牌色与语义色常量（如 `pastableOrange`）。
- `Color.toHex()` 支持颜色回写缓存（如自适应色缓存）。

### 3) 文本与时间工具

- `Date.timeAgoDisplay()` 输出相对时间（`RelativeDateTimeFormatter`）。
- `String.shortened(to:)` 执行安全截断，用于标题与预览文本上限控制。

### 4) Pasteboard 类型常量

扩展了多个自定义/特殊类型：

- 图像：`heic`, `jpeg`
- 通用剪贴板：`universalClipboard`
- 忽略型：`autoGenerated`, `concealed`, `transient`, `fromPastable`
- 特定应用附加类型：Safari/Chromium/Apple Notes/Microsoft 链接相关

统一了采集层与模型层对 type 字符串的判断口径。

### 5) 快捷键名称扩展

- 统一定义 `KeyboardShortcuts.Name.togglePanel`。
- 默认绑定 `Cmd + Shift + V`。

### 6) 国际化文案

- `Localizable.strings` 提供菜单、分类、设置页等多语言文本。
- UI 中通过 key（如 `settings.general.title`）进行动态加载。

## 与业务层关系

- `ThemeManager/Color` 被 `CategoryFilter/CardCell` 广泛调用。
- `Date/String` 被 `CardCell/HistoryItem` 调用。
- `NSPasteboard` 类型扩展直接支撑 `Clipboard` 与 `HistoryItem`。
- 本地化文案覆盖主界面和设置页核心文案。

## 已知约束

- 主题模式虽有多种定义，但当前管理器实际锁定为 `adaptive`。
- `ThemePalette` 预置方案未暴露完整设置入口。
- 本地化文案覆盖了主流程，但某些硬编码文本仍存在（如 About 页版本号）。
