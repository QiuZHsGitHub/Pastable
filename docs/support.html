快速上手

  1. 从 Mac App Store 安装并打开 Pastable。应用会以一个安静的图标待在菜单栏。
  2. 在任意应用中按 ⌘ ⇧ V，面板会贴着当前屏幕底部出现。
  3. 直接输入关键词搜索；用 ← → 选卡片，按 ↩ 粘贴，或点击卡片。
  4. 想让选中的内容自动粘贴到当前应用，请在首次提示时授予「辅助功能」权限；不授权也能正常复制。

系统要求

  • macOS 15.5 或更高版本。
  • 安装包约为 2 MB，无需额外下载组件。
  • 可选：iCloud（跨 Mac 同步）、辅助功能（自动粘贴）。两项都不影响基础使用。

常见问题

按下快捷键没有反应？

先确认 Pastable 正在运行（菜单栏有图标）。如果快捷键被其他效率工具占用（Raycast、Alfred、输入法等），请打开 Pastable 设置，重新录制一个组合。

全屏应用、多显示器和切换桌面空间都受支持；面板会出现在当前屏幕的底部。

点击卡片只复制了，没有自动粘贴？

这是「辅助功能」权限未授权的表现。打开「系统设置 → 隐私与安全性 → 辅助功能」，启用 Pastable，然后退出并重新打开应用。

没有该权限时，内容仍会写入剪贴板，手动按 ⌘ V 即可粘贴。

某条内容没有进入历史？

请检查「设置 → 保存类型」是否关闭了对应类型（文本 / 图片 / 文件）。密码管理器等应用可能把剪贴板标记为机密内容，系统不会把它交给第三方应用，这是预期行为。

历史记录占用空间越来越大？

图片入库时会自动生成缩略图，但原图仍可能较大。可以在设置中查看存储占用、设置保留时长与数量上限，或手动清空历史。

首次发现历史超过限制时，Pastable 会询问「清理 / 全部保留 / 稍后」，不会擅自删除。

如何在多台 Mac 之间同步？

在设置中开启「iCloud 同步」，并确保两台 Mac 登录同一个 Apple ID、已在系统中允许 Pastable 使用 iCloud。首次同步需要一点时间。

历史通过 CloudKit 私有数据库传输，只有你的 Apple ID 可以访问，开发者无法查看。关闭同步后不会再写入新数据。

如何彻底删除数据？

在设置中清空历史，然后退出并删除 Pastable。删除应用不会自动删除已同步到 iCloud 的记录；iCloud 数据由你的 Apple ID 管理，可在「系统设置 → Apple ID → iCloud → 管理账户存储」中查看是否有 Pastable 数据。

快捷键可以自定义吗？

可以。打开设置 → 通用 → 全局快捷键，录制新的组合即可。建议避开系统或其他效率工具已经占用的快捷键。

评分弹窗什么时候出现？

从 1.2.1 起，评分弹窗不会在启动时出现：第一次成功粘贴后才会标记，并在之后某次打开面板时由系统询问；也可以随时在「设置 → 关于 → 在 Mac App Store 评分」主动评价。

是订阅制吗？

不是。Pastable 一次买断，没有订阅、没有内购、没有账号。价格以 Mac App Store 页面显示为准。

权限设置

只有「自动粘贴」需要额外权限。开启方式：

  1. 打开「系统设置 → 隐私与安全性 → 辅助功能」。
  2. 在列表中找到 Pastable 并打开开关；如果没有，点击 + 从「应用程序」中添加。
  3. 修改授权后，建议退出并重新打开 Pastable。

该权限用于向当前应用发送一次 ⌘ V，通过系统标准接口实现。你可以随时关闭它，应用会退回「仅复制」模式。

Support

Getting started

  1. Install and open Pastable from the Mac App Store. It lives quietly in the menu bar.
  2. In any app, press ⌘ ⇧ V. The shelf appears at the bottom of the current screen.
  3. Start typing to search. Use ← → to select a card, then ↩ to paste, or just click it.
  4. To paste automatically into the frontmost app, grant Accessibility when prompted. Without it, the app still copies to the clipboard.

System requirements

  • macOS 15.5 or later.
  • The app is about 2 MB and downloads no additional components.
  • Optional: iCloud (sync across Macs) and Accessibility (auto paste). Neither is required for basic use.

Frequently asked questions

Nothing happens when I press the shortcut.

Make sure Pastable is running (look for its menu bar icon). If another utility such as Raycast, Alfred or an input method already uses that combination, open Pastable Settings and record a different one.

Fullscreen apps, multiple displays and Spaces are supported; the shelf opens on the current screen.

Clicking a card copies, but does not paste.

That means Accessibility is not granted. Open System Settings → Privacy & Security → Accessibility, enable Pastable, then quit and reopen the app.

Without the permission the content is still copied; press ⌘ V manually.

An item never shows up in history.

Check Settings → Save types to see whether that type (text / image / file) is disabled. Password managers may mark clipboard contents as confidential; macOS then does not hand them to third-party apps, which is expected.

History is taking up too much space.

Images get thumbnails, but originals can still be large. Check storage usage in Settings, set a retention window or capacity cap, or clear history manually.

The first time history exceeds your limit, Pastable asks before cleaning up — it never deletes silently.

How do I sync across multiple Macs?

Turn on iCloud Sync in Settings and make sure both Macs use the same Apple ID and allow Pastable to use iCloud. The first sync may take a moment.

History travels through a private CloudKit database accessible only to your Apple ID; the developer cannot view it. Turning sync off stops new writes.

How do I delete everything?

Clear history in Settings, then quit and delete Pastable. Deleting the app does not remove records already synced to iCloud; that data is managed by your Apple ID. Check System Settings → Apple ID → iCloud → Manage Account Storage to see whether Pastable data is listed.

Can I change the shortcut?

Yes. Open Settings → General → Global shortcut and record a new combination. Avoid combinations already claimed by macOS or other utilities.

When does the review prompt appear?

Starting with 1.2.1, the review prompt never appears at launch. The first successful paste marks the moment, and the system may ask on a later panel open. You can also rate any time from Settings → About → Rate on the Mac App Store.

Is this a subscription?

No. Pastable is a one-time purchase with no subscription, no in-app purchases and no account. The price shown on the Mac App Store applies.

Accessibility permission

Only Auto Paste needs an extra permission:

  1. Open System Settings → Privacy & Security → Accessibility.
  2. Find Pastable and turn it on. If it is missing, click + and add it from Applications.
  3. After changing the permission, quit and reopen Pastable.

The permission sends a single ⌘ V to the frontmost app using standard system APIs. You can revoke it at any time; the app falls back to copy-only.

Purchases and refunds

Apple handles purchases, billing and refunds. To request a refund, visit reportaproblem.apple.com, choose the purchase and follow the steps. The developer cannot issue refunds directly.

If you cannot download or install, confirm macOS 15.5 or later and check your App Store account and connection.
